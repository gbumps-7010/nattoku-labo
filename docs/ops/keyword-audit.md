# ナットクLabo キーワード設計の監査（2026-10-20）

**正規の置き場:** `docs/ops/keyword-audit.md`（Claude Code はルート `CLAUDE.md` → [`handoff-claude.md`](./handoff-claude.md) のあとで読む）。

対象：サイトマップ掲載の81ページ（＋サイトマップ外の製品ページ）
データ：月間検索数はラッコキーワード（Google・日本・直近12か月平均）。順位はラッコの推定とサーチコンソール（7/17〜10/16）。
前回の修正（トップ・エコバックスのタイトル、製品ページの本文）は本番に反映済みであることを確認しました。

---

## 結論

1. **狙いキーワードがタイトルから読み取れるのは約半分。** 製品ページは全ページ同じ型（`{型番}の口コミ・評判｜{ブランド}`）なので一見明確ですが、**ユーザーが実際に検索する表記とタイトルの表記が一致していない**ページが多くあります。特にルンバとEufy。
2. **狙いが不適切なページが3系統あります。**
   - 価格帯別比較6ページ：狙っている「ロボット掃除機 ○万円」は月0〜30検索しかない
   - フローリングランキング：「ロボット掃除機 フローリング」は月40。同じ内容で「水拭き」（月2,900）が取れる
   - 小さいロボット掃除機ガイド：「小さい」より「小型」（880）「一人暮らし」（880）が主戦場
3. **同じキーワードを複数ページで奪い合っている（カニバリ）組が5つあります。**
4. **需要が大きいのに受け皿ページがないキーワード**があります（日本製 1,900、段差 880、ルンバ比較系 4,400 など）。

## A. 製品ページ（51＋α）

### A-1. 共通ルール：タイトルを「検索される表記」に揃える

検索数が集まるのは「ブランド＋型番」の素の形です。「口コミ」「レビュー」付きは月10〜140程度なので、**型番部分の表記が検索語と一致しているか**が最重要です。

推奨フォーマット：
```
{ブランド英字} {型番}の口コミ・評判｜{不満点のひとこと}｜ナットクLabo
例：Eufy X10 Pro Omniの口コミ・評判｜故障・水漏れの声と対策｜ナットクLabo
```
- 先頭に英字ブランド（Eufy / Dreame / SwitchBot / Roborock）を付ける
- ® や ™ は外す（検索語に含まれず、文字数を消費するだけ）
- 末尾の「｜ドリーミー（Dreame）」のようなカタカナ併記は h1 か本文に移してよい

## E. 技術面で残っている点

1. **サイトマップに載っていない製品ページがある。** roomba-plus-575-combo-autowash（ルンバ 575 は月1,000検索）は公開されていますが sitemap.xml にありません。ランキングに載っている D20 Ultra、Eufy Omni S2 も同様の可能性があるので、製品データからサイトマップを自動生成してください。
2. **サイトマップの lastmod が全81ページ同じ日付（2026-10-18）。** 実際に更新したページだけ日付が変わるようにすると、クロールの優先度づけに役立ちます。
3. **JSON-LD（Product / Review / BreadcrumbList）が入っているか未確認。** こちらのツールでは script タグが読めないため、リッチリザルトテストで確認してください。
4. **件数の不一致。** ほぼ全ページで、description・表の口コミ件数（総数）と本文の件数（採用数）が数件ずれています。「総口コミ○件（うち分析対象○件）」に統一してください。
5. **「最も高い」「総合1位」が表の点数と合わないページ。** dreame、roborock、ecovacs、cat、pet、height。比較サイトとして致命的なので、自動生成のロジックを確認してください。
6. **プレースホルダーの残り。** 「かんたんリンクを読み込み中…」「価格読込中…」がHTMLに残っているページ多数（anker、roborock、cost-performance、height、small、compare各ページ、rankings）。JS実行前は出さないようにしてください。
7. **口コミ0件の項目に点数が付いている。** F20・F20 Plus・X30 Ultra（バッテリー0点表示）など。0件の項目は「—（データ不足）」にしてください。
8. **不可視文字（U+2060）は引き続き本文に入っている。** 太字の崩れの原因にもなっています（前回 P2-1）。
