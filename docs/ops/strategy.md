## 0. 前提

- **担当:** 記事・タイトル・本文・導線の**編集まで** Claude Code が行う。Cursor は元データ作成（スクショ→JSON）と push。管理表（Google Sheets）は指示があったときだけ Claude Code が編集する。
- **聖域:** 点数・信頼度・順位計算は変えない。表示とデータの不一致は表示バグとして扱う。aggregateRating なし、価格の全面更新は保留、低口コミ機種もランキングから外さない。
- **現状（GSC、7/17〜10/16）:**
  - 3か月でクリック117・表示6,091。半分（55）が直近28日。
  - 10/10以降、表示は1日約300回、平均順位は9位前後まで上がった。
  - 10/18〜10/20 の修正（タイトル・プリレンダ・404整理）の効果はまだ入っていない。
  - デバイス: モバイルがクリックの73%（平均順位 11.1、PC は 17.4）。
  - 検索での見え方: 商品スニペット 1,920 表示、レビュースニペット 2 表示。

## 1. 勝ち方の原則

1. **検索ボリュームより勝てる見込みを優先する。** すでに10位前後にいる語のCTR改善が最優先。ビッグワードは後回し。ボリュームは同じ段の中の並べ替えにだけ使う。
2. **独自データで勝負する。** 不満点・故障率・機能別スコアは他サイトにない。型番の口コミ、機種同士の比較、不安系（寿命・後悔）で生かす。
3. **製品ページで納得してから買ってもらう。** 比較系ページからは製品ページへ送り、不満点と対策を読んだ直後に購入ボタンを出す。

## 3. 導線と購入までの設計

| 段階 | 受け皿 |
|---|---|
| ① 不安 | 寿命・後悔・どこの国の記事 |
| ③ 条件で絞る | ガイド・ランキング |
| ④ ブランドで比べる | メーカー比較ページ |
| ⑤ 機種を決める | 製品ページ・比較記事 |
| ⑥ 購入 | 製品ページの購入ボタン |

**製品ページ（今は購入ボタン以外がほぼ行き止まり）**
- 「この機種で迷う人の比較候補」を3機種（同価格帯の上位機・同メーカーの上下・姉妹機）。点数は既存値の引用のみ。
- 関連ガイド・ランキングと、メーカー比較ページへのリンク。
- 購入ボタンは3か所: 上部・**「主な不満点と対策」の直後**・下部。故障の不満が多い機種には公式保証特典（`official-perks.js`）を合わせる。

**購入先の主役（ロボット掃除機管理表で確認済み）**

| メーカー | 主役 |
|---|---|
| iRobot・SwitchBot（A8）、Dreame（afi-b）、Anker（バリューコマース） | 公式ストア＋保証特典 |
| ECOVACS・Roborock（公式アフィリなし） | 楽天・Amazon・Yahoo のかんたんリンク |

## 4. 改善点の一覧

### 表示・SEOの実装（Claude Code）
1. エコバックス製品3ページのタイトル・説明文
2. 製品タイトルの書式（`scripts/prerender-product-pages.js` の `buildMetadata` と `products/js/product-loader.js` の `buildSeoMetadata` を**同時に**直す。片方だけだと表示時に元に戻る）
3. 製品ページへの比較候補・関連リンク・不満点直後の購入ボタン
4. 静音ランキングの h1・タイトル、Tier B のタイトル
5. 比較記事（405 vs 505 など）と Tier A の新規ページ

### バグ・食い違い（表示側。点数は変えない）
6. ブラウザ側で JSON-LD が Review なしの Product に上書きされる（`products/js/product-loader.js:187`）。レビュースニペットが出ない原因の候補
7. ブラウザ側でパンくずが `productName`（® 付き）に上書きされ、構造化データとずれる（`products/js/product-loader.js:312`）
8. 総合点の計算が5か所に別実装（`scripts/lib/overall-score.js`、メーカー比較・ランキング・ガイド・価格帯の各生成スクリプト）。丸めや使う項目数が違い、「最も高い」と表の点数不一致の原因候補。表示を揃える調査をする（計算式自体は変えない）
9. 本文の U+2060（`ja_wrap()` / `jaWrap()`）
10. 「読み込み中…」のプレースホルダー残り、口コミ0件項目の「—」表示
11. 総口コミ数と分析対象件数の表記統一

### データ・管理表（Cursor／管理表）
12. ルンバ575 の HP掲載と直販リンク
13. Eufy Omni S2 の価格不一致（管理表 ¥199,900 ／ JSON ¥249,900）
14. Qrevo CurvC が管理表で HP掲載 TRUE のまま（サイトでは 410）
15. sitemap の lastmod が全ページ同日（`scripts/generate-sitemap.js` がファイル更新日時を使うため）
16. ガイドのインデックス確認（3か月で表示があるのは cheap のみ。GSC の URL 検査）
